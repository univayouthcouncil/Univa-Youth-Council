UNIVA Youth Council Homepage

Files included:
- index.html — editable responsive homepage
- univa-logo.png — your uploaded UNIVA logo

Members panel:
Open index.html in a text editor and find the `const members=[...]` section near the bottom. Edit each member's name, role, details, and photo filename. Put photo files in the same folder as index.html. Each member has a View Details button that opens a profile window.

This is a standalone HTML website for Netlify, GitHub Pages, or similar static hosting. Google Sites does not directly import a complete HTML layout as editable Google Sites sections.
